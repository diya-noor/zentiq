# Zentiq Academy

A responsive Next.js App Router site based on the supplied Zentiq design references.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` after the development server starts. Use `npm run build` to create a production build and `npm start` to serve it.

## Pages

- `/` — Zentiq homepage
- `/services` — engineering services and project estimate form
- `/courses` — academy catalog with search, category and level filters, and price sorting
- `/dashboard` — student console

Course imagery is served from `public/`.
